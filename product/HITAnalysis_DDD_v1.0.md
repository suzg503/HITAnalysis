## 1. 登录与认证模块

### 1.1 功能概要

用户通过机构选择 + 用户名/密码登录系统，系统自动根据用户角色分配权限和默认页面。

### 1.2 详细交互流程

#### 流程图：登录

```
用户 → 打开系统 → 显示登录页
                              ↓
                    ┌────────────────────────┐
                    │  1. 机构选择 (下拉框)   │
                    │  2. 用户名输入          │
                    │  3. 密码输入            │
                    │  4. [登录] 按钮         │
                    └────────────────────────┘
                              ↓
                    验证机构 + 用户名 + 密码
                              ↓
                    [失败] → 显示错误信息 → 回到登录页
                    [成功] → 鉴权获取角色和权限 → 跳转首页
                                                ↓
                                    ┌──────────────┬───────────┐
                                    │ 首页定位逻辑 │            │
                                    │ 无AI权限  │   跳转标准报表中心 │
                                    │ 有AI权限  │   跳转AI洞察中心 │
                                    └──────────────┴───────────┘
```

### 1.3 页面状态与元素

#### 登录页面

| 元素 | 说明 | 交互 |
|------|------|------|
| **机构选择** | 下拉框，列出所有可用机构 | 必选项，默认选中最近登录机构 |
| **用户名** | 文本输入框 | 必填，支持工号/手机号/邮箱 |
| **密码** | 密码输入框 | 必填，支持密码可见性切换 |
| **登录按钮** | 主按钮 | 点击触发校验和登录 |
| **忘记密码** | 链接 | 跳转密码重置流程（需管理员介入） |
| **联系管理员** | 链接 | 打开企业微信/邮件等 |
| **安全提示** | 底部静态信息 | "本地部署 · 数据不出院 · 传输加密" |

#### 校验规则

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 机构 | 必填 | "请选择所属机构" |
| 用户名 | 必填，1-50字符 | "请输入用户名" |
| 密码 | 必填，8-32字符 | "请输入密码" |
| 登录失败 | 5 次锁定 | "密码错误，还剩 X 次机会" |
| 账号锁定 | 锁定 30 分钟 | "账号已锁定，请 30 分钟后重试或联系管理员" |

### 1.4 异常处理

| 场景 | 状态 | 提示信息 |
|------|------|---------|
| 用户名/密码错误 | 正常继续 | "用户名或密码错误" |
| 机构不匹配 | 正常继续 | "该用户不属于此机构" |
| 账号锁定 | 正常继续 | "账号已锁定，请联系管理员" |
| 系统维护 | 503 页面 | "系统维护中，预计恢复时间：XX" |
| AI 服务不可用 | 登录成功但降级 | 弹出提示"AI 服务暂时不可用，已切换至标准报表模式" |

## 2. AI 洞察中心

```
AI 洞察中心
├── 📂 目录树
│     ├── 我的分析
│     │     ├── 自定义文件夹 1
│     │     ├── 自定义文件夹 2
│     │     └── 未分类（默认）
│     └── 分享给我的分析（无则隐藏）
├── 💬 AI 对话面板
│     ├── 输入区域
│     │     ├── 文本输入框
│     │     ├── 语音输入按钮
│     │     ├── 发送按钮
│     │     └── 快捷指令（标签/按钮）
│     ├── 对话展示区
│     │     ├── 用户消息
│     │     ├── AI 回复（解析中/已确认/报错）
│     │     └── AI 解析确认卡片
│     └── 操作区
│           ├── 清空对话
│           └── 新对话

      ├── 维度筛选器

      ├── 下钻按钮
      ├── 导出按钮
```

### 2.2 AI 自然语言查询

#### 输入区域

| 元素 | 说明 | 交互 |
|------|------|------|
| **文本输入框** | 多行文本框，占位符"请描述您的分析需求" | Enter 发送，Shift+Enter 换行 |
| **语音输入按钮** | 麦克风图标 | 长按开始录音，松开发送 |
| **发送按钮** | 按钮"发送" | 仅输入非空时可用 |
| **快捷指令** | 预设常用查询 | 点击填入输入框或直接触发 |

#### 快捷指令预设

| 分类 | 示例指令 |
|------|---------|
| **趋势分析** | "查看近半年门诊量趋势" |
| **对比分析** | "对比心内科和呼吸科抗生素使用率" |
| **异常分析** | "找出本月抗生素使用超标的科室" |
| **目标达成** | "心内科本月目标值达成情况" |
| **排名分析** | "按门诊量排名前三的科室" |

### 2.3 AI 解析确认卡片

#### 状态流转

```
用户输入 → AI 解析中 → 展示确认卡片 → 用户确认
                              ↓
                    [确认] → 生成预览
                    [修改] → 回显可编辑字段 → 重新解析
                    [拒绝] → 回到空状态，保留对话记录
```

#### 确认卡片内容

| 字段 | 说明 | 可编辑性 |
|------|------|---------|
| **指标** | 解析出的指标名称 | ✅ 可修改，下拉选择 |
| **维度** | 解析出的维度列表 | ✅ 可修改，多选/增删 |
| **时间范围** | 解析出的时间范围 | ✅ 可修改，日期选择器 |
| **计算逻辑** | 同比/环比/汇总等 | ✅ 可修改，下拉选择 |
| **筛选条件** | 科室/医生等筛选 | ✅ 可修改，条件编辑器 |
| **[确认生成]** | 主按钮 | - |
| **[修改条件]** | 次按钮 | - |

#### 校验规则

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 指标 | 必填，需在指标库中存在 | "请至少选择一个指标" |
| 维度 | 必填，需在维度库中存在 | "请至少选择一个维度" |
| 时间范围 | 必填，结束 >= 开始 | "时间范围无效" |
| 权限 | 数据权限范围内 | "超出数据权限范围，请联系管理员" |

#### 预览面板元素

| 元素 | 说明 | 交互 |

| **保存按钮** | 💾 保存 | 打开保存对话框 |

#### 图表渲染规则

| 场景 | 默认图表类型 | 说明 |
|------|-------------|------|

| 单指标 + 分类维度 | 柱状图 | 展示分类对比 |

### 2.5 保存报表对话框

#### 保存流程

```
用户点击【保存】
    ↓
弹出对话框
    ↓
┌─────────────────────────────┐
│ 报表名称（必填，自动建议）     │
│ 选择/新建文件夹（默认"未分类"） │
│ 可见性：私有/科室共享/院区共享 │
│ [取消]          [保存]        │
└─────────────────────────────┘
    ↓
校验
    ↓
[成功] → 报表保存 → 更新目录树 → 提示"保存成功"
[失败] → 显示错误 → 保留对话框
```

#### 字段说明

| 字段 | 必填 | 默认值 | 规则 |
|------|------|--------|------|
| **报表名称** | 是 | AI 建议名称 | 2-50 字符，不可为空 |
| **选择/新建文件夹** | 否 | "未分类" | 可新建文件夹（2-30 字符） |
| **可见性** | 是 | "私有" | 私有/科室共享/院区共享 |

#### 可见性规则

| 可见性 | 可见范围 | 约束 |
|--------|---------|------|
| **私有** | 仅自己可见 | 不受权限影响 |
| **科室共享** | 同一科室成员可见 | 需有科室数据权限 |
| **院区共享** | 同一院区成员可见 | 需有院区数据权限 |

| **重命名报表** | 右键菜单 | 报表所有者 |
| **删除报表** | 右键菜单 | 报表所有者 |

| 场景 | 确认对话框 | 操作 |
|------|-----------|------|

### 3.4 下钻分析

#### 下钻触发

| 触发方式 | 说明 |
|---------|------|
| **图表元素点击** | 点击柱状图的柱子、饼图的扇区等 |
| **数据行点击** | 点击表格中的某一行 |
| **下钻按钮** | 主动选择下钻维度 |

#### 下钻交互

```
用户点击图表元素
    ↓
系统高亮选中元素
    ↓
面包屑更新：全院 > XX院区 > XX科室
    ↓
图表刷新为下级维度数据
    ↓
维度筛选器更新为当前层级可用筛选
    ↓
支持：继续下钻 / 点击面包屑返回上级 / 叠加筛选
```

#### 下钻层级限制

| 维度 | 层级 | 路径 |
|------|------|------|
| 组织维度 | 3 级 | 院区 → 科室 → 医生 |
| 时间维度 | 5 级 | 年 → 季 → 月 → 日 → 时 |
