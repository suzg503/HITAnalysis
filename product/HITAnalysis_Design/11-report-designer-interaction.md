# 报表设计器交互设计文档

## 1. 功能概述

报表设计器是HITAnalysis平台的核心功能模块，用于自定义创建、编辑和管理数据报表。支持从数据源配置、指标维度选择、图表类型设置到报表保存发布的完整流程。

---

## 2. 交互流程

### 2.1 主流程（新建报表）

```
[新建报表] → [选择数据源] → [配置指标维度] → [选择图表类型] → [设置筛选条件] → [预览调整] → [保存发布]
```

### 2.2 状态流转

| 状态 | 用户操作 | 系统反馈 | 下一状态 |
|------|----------|----------|----------|
| 初始状态 | 点击"新建报表" | 打开设计器 | 数据源选择 |
| 数据源选择 | 选择数据源 | 加载字段列表 | 指标维度配置 |
| 指标维度配置 | 拖拽配置指标 | 实时更新预览 | 图表类型选择 |
| 图表类型选择 | 选择图表类型 | 更新图表预览 | 筛选条件设置 |
| 筛选条件设置 | 设置筛选条件 | 筛选数据 | 预览调整 |
| 预览调整 | 微调样式 | 实时更新 | 保存发布 |
| 保存发布 | 填写报表信息 | 保存成功 | 完成 |

---

├────────────┬─────────────────────────────────────────────────────┤

│ 菜单       │  ┌────────────────────────────────────────────────┐ │
│ （纵向）   │  │ 工具栏：[新建] [编辑] [删除] [导出] [预览]     │ │
│            │  ├────────────────────────────────────────────────┤ │
│ > 报表列表 │  │                                                  │ │
│   - 日报表 │  │  ┌───────────┐  ┌─────────────────────────────┐ │ │

│            │  │  │           │  │                             │ │ │
│ > 已保存   │  │  │ 数据源    │  │                             │ │ │
│            │  │  │ 指标维度  │  │                             │ │ │
│ > 共享报表 │  │  │ 图表类型  │  │                             │ │ │

│            │  │                                                  │ │

### 3.2 设计器工作区布局

报表设计器采用**左右分栏**布局：
- **左侧配置面板（280px）**：数据源、指标维度、图表类型、筛选条件配置
- **右侧预览区（flex-1）**：实时图表预览、数据表格预览

## 4. 交互细节

### 4.1 数据源选择

**交互方式**：下拉选择 + 搜索筛选

| 元素 | 设计 |
|------|------|
| 数据源下拉框 | 显示已配置的数据源列表，支持搜索 |
| 数据源信息 | 选择后显示数据源详情（字段数、更新频率） |
| 字段列表 | 展示可用字段，按类型分组（数值型、文本型、日期型） |

**状态设计**：
- 默认态：显示"请选择数据源"
- 选择态：显示数据源名称，展开字段列表
- 加载态：选择后显示loading spinner

### 4.2 指标维度配置

**交互方式**：拖拽配置 + 点击添加

| 元素 | 设计 |
|------|------|
| 指标配置区 | 拖拽区域，显示已配置的指标 |
| 维度配置区 | 拖拽区域，显示已配置的维度 |
| 字段卡片 | 可拖拽的字段元素，双击添加 |
| 配置项卡片 | 已配置项，支持删除、排序 |

**拖拽交互**：
- 字段卡片拖拽到配置区 → 自动添加
- 配置项卡片拖拽排序 → 更新顺序
- 配置项卡片拖拽出配置区 → 移除

**视觉反馈**：
- 拖拽中：卡片缩小、opacity降低、配置区高亮
- 添加成功：卡片有success动画
- 移除成功：卡片有淡出动画

### 4.3 图表类型选择

**交互方式**：点击选择 + 卡片展示

| 图表类型 | 图标 | 适用场景 |
|----------|------|----------|
| 柱状图 | 📊 | 分类对比 |
| 折线图 | 📈 | 趋势分析 |
| 饼图 | 🥧 | 占比分布 |
| 表格 | 📋 | 详细数据 |
| 组合图 | 📊📈 | 多维度对比 |
| 仪表盘 | ⏱️ | KPI指标 |

**状态设计**：
- 未选择：所有卡片默认态
- 已选择：选中卡片高亮，其他卡片淡出
- hover：卡片放大、border高亮

### 4.4 筛选条件设置

**交互方式**：条件组合器 + 表达式构建

| 元素 | 设计 |
|------|------|
| 筛选字段选择 | 下拉选择字段 |
| 条件操作符 | 下拉选择（等于、大于、包含等） |
| 条件值 | 输入框或下拉选择 |
| 条件组合 | AND/OR逻辑组合 |
| 条件列表 | 已添加条件列表，支持删除 |

**交互流程**：
1. 选择筛选字段
2. 选择操作符
3. 输入/选择条件值
4. 点击"添加条件"
5. 条件添加到列表
6. 可继续添加组合条件

### 4.5 预览区

**交互方式**：实时渲染 + 刷新控制

| 元素 | 设计 |
|------|------|
| 图表预览 | 基于当前配置实时渲染图表 |
| 数据表格 | 显示图表背后的数据表格 |
| 预览刷新 | 自动刷新（配置变化）+ 手动刷新按钮 |
| 预览工具栏 | 切换图表/表格视图、缩放、导出 |

**自动刷新规则**：
- 指标维度变化 → 500ms延迟后刷新（避免频繁刷新）
- 图表类型变化 → 立即刷新
- 筛选条件变化 → 立即刷新

### 4.6 保存发布

**交互方式**：模态对话框

| 元素 | 设计 |
|------|------|
| 报表名称 | 输入框，必填 |
| 报表分类 | 下拉选择分类 |
| 报表描述 | 多行文本框，可选 |
| 更新频率 | 下拉选择（手动、每日、每周、每月） |
| 权限设置 | 勾选框（私有、部门共享、全院共享） |

## 5. 状态设计

### 5.1 空状态

**场景**：新建报表初始状态

**设计**：
- 配置面板显示引导提示
- 预览区显示空状态插图
- 提示文字："请选择数据源开始配置报表"

### 5.2 加载状态

**场景**：数据源加载、图表渲染

**设计**：
- 预览区显示骨架屏
- 配置面板显示loading spinner
- 状态提示："正在加载数据..."

### 5.3 错误状态

**场景**：数据源异常、配置错误

**设计**：
- 错误提示卡片
- 红色语义色边框
- 错误原因文字
- 操作建议按钮

### 5.4 成功状态

**场景**：保存成功、配置完成

**设计**：
- Toast提示（顶部居中）
- 成功绿色语义色
- 3秒自动消失

### 8.3 间距使用

- 配置面板内间距：16px
- 配置项间距：8px
- 区块间距：24px
- 左右分栏间距：24px

## 9. 交互动效

### 9.1 拖拽动效

- 开始拖拽：scale(0.95), opacity(0.7), 0.15s ease
- 拖拽中：跟随鼠标，配置区高亮
- 结束拖拽：scale(1), opacity(1), 0.15s ease + success pulse

### 9.2 面板展开动效

- 展开：height 0 → auto, 0.25s ease
- 收起：height auto → 0, 0.25s ease

### 9.3 Toast动效

- 进入：translateY(-20px) → 0, opacity 0 → 1, 0.25s ease
- 退出：opacity 1 → 0, 0.15s ease, 延迟3s后执行

## 附录：用户操作路径

### 新建报表完整路径

```
1. 顶部菜单 → 报表中心
2. 左侧菜单 → 报表列表 → 点击"新建报表"按钮
3. 配置面板 → 数据源选择 → 选择数据源
4. 配置面板 → 拖拽字段到指标区/维度区
5. 配置面板 → 点击选择图表类型
6. 配置面板 → 设置筛选条件（可选）
7. 预览区 → 查看实时预览，微调配置
8. 操作栏 → 点击"保存草稿"或"发布报表"
9. 弹出保存对话框 → 填写报表信息 → 确认保存
```

### 编辑报表路径

```
1. 左侧菜单 → 报表列表 → 点击已有报表
2. 工具栏 → 点击"编辑"
3. 进入编辑模式（加载已有配置）
4. 配置面板 → 修改配置
5. 预览区 → 查看实时更新
6. 操作栏 → 点击"保存"
```
