## 1. 模块概述

### 1.1 模块定位

指标管理模块是HITAnalysis平台的**核心数据治理模块**，负责医疗业务指标的统一定义、分类、管理和应用。通过标准化的指标体系，确保数据分析的一致性和可追溯性。

### 1.2 模块结构

```
指标管理
├── 📂 指标分类管理
│   ├── 分类树管理
│   ├── 分类属性维护
│   └── 分类排序与层级
├── 📚 指标库管理
│   ├── 指标列表查询
│   ├── 指标筛选与搜索
│   ├── 批量导入导出
│   └── 指标状态管理
├── 📝 指标定义
│   ├── 新增指标
│   ├── 编辑指标
│   ├── 指标属性配置
│   └── 指标发布流程
├── 🎯 指标应用配置
│   ├── 应用管理
│   ├── 指标关联
│   ├── 权限配置
│   └── 应用状态控制
└── 🔍 指标选择器
    ├── 指标搜索
    ├── 分类筛选
    ├── 批量选择
    └── 指标预览
```

### 1.3 核心价值

- **统一标准**：建立医院统一的指标定义标准，避免口径不一致
- **数据治理**：通过分类管理和生命周期管理，确保指标质量
- **灵活应用**：支持指标的多场景应用（报表、看板、API等）
- **可追溯性**：完整的指标创建、修改、使用记录

## 2. 指标分类管理

### 2.1 功能概述

指标分类管理用于构建指标的层级分类体系，通过树形结构对指标进行分类管理，支持多级分类、拖拽排序、批量操作等功能。

### 2.2 页面设计

#### 2.2.1 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│ 指标管理 > 指标分类                                    [关闭] │
├─────────────────────────────────────────────────────────────┤
│ ┌─────────────────┐  ┌───────────────────────────────────┐ │
│ │ 指标分类        │  │ 分类信息                          │ │
│ ├─────────────────┤  ├───────────────────────────────────┤ │
│ │ 🔍 搜索框       │  │ 🔍 [请输入分类名称] [查询] [重置] │ │
│ ├─────────────────┤  │                                   │ │
│ │ 📁 指标分类      │  │ [+ 新增]                         │ │
│ │   ├─ 基础指标    │  ├───────────────────────────────────┤ │
│ │   ├─ 业务指标    │  │ 分类名称 | 分类编码 | 排序 | 操作 │ │
│ │   ├─ 衍生指标    │  ├───────────────────────────────────┤ │
│ │   └─ 技术指标    │  │ 基础指标 | BASE_INDEX | 1  | 修改 │ │
│ │                 │  │ 业务指标 | BUSINESS_INDEX | 2 | 修改 │ │
│ │ [新增子分类]    │  │ 衍生指标 | DERIVED_INDEX | 3 | 修改 │ │
│ │ [编辑] [删除]   │  │ 技术指标 | TECH_INDEX | 4  | 修改 │ │
│ └─────────────────┘  └───────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

#### 2.2.2 左侧树形结构

- **根节点**：指标分类
- **一级分类**：基础指标、业务指标、衍生指标、技术指标
- **二级分类**：支持无限层级扩展
- **节点操作**：
  - 新增子分类：在当前节点下添加子分类
  - 编辑：修改分类名称、编码、排序
  - 删除：删除分类（需检查是否有关联指标）

#### 2.2.3 右侧列表

- **筛选条件**：
  - 分类名称：模糊搜索
  - 查询按钮：执行搜索
  - 重置按钮：清空条件

- **表格列**：
  - 分类名称：显示分类中文名称
  - 分类编码：显示分类唯一标识（大写英文+下划线）
  - 排序：显示同级分类的排序值
  - 创建时间：记录创建时间
  - 操作：修改、删除

- **操作按钮**：
  - 新增：创建新分类
  - 修改：编辑分类信息
  - 删除：删除分类（需二次确认）

### 2.3 数据模型

#### 2.3.1 指标分类表（metric_category）

| 字段名 | 类型 | 长度 | 必填 | 说明 |
|--------|------|------|------|------|
| category_id | BIGINT | - | 是 | 分类ID（主键） |
| category_name | VARCHAR | 100 | 是 | 分类名称 |
| category_code | VARCHAR | 50 | 是 | 分类编码（唯一） |
| parent_id | BIGINT | - | 否 | 父分类ID（0表示根节点） |
| level | INT | - | 是 | 层级（1=一级，2=二级...） |
| sort_order | INT | - | 是 | 排序值 |
| description | VARCHAR | 500 | 否 | 分类描述 |
| status | TINYINT | - | 是 | 状态（1=启用，0=停用） |
| created_by | BIGINT | - | 是 | 创建人ID |
| created_time | DATETIME | - | 是 | 创建时间 |
| updated_by | BIGINT | - | 否 | 更新人ID |
| updated_time | DATETIME | - | 否 | 更新时间 |

#### 2.3.2 索引设计

```sql
-- 主键索引
PRIMARY KEY (category_id)

-- 唯一索引
UNIQUE KEY uk_category_code (category_code)

-- 普通索引
KEY idx_parent_id (parent_id)
KEY idx_status (status)
KEY idx_sort_order (sort_order)
```

### 2.4 业务流程

#### 2.4.1 新增分类流程

```
1. 用户点击"新增"按钮
   ↓
2. 弹出新增分类弹窗
   ↓
3. 用户填写：
   - 分类名称（必填）
   - 分类编码（必填，自动生成或手动输入）
   - 父分类（默认为当前选中节点）
   - 排序值（默认为同级最大值+1）
   - 分类描述（选填）
   ↓
4. 前端校验：
   - 分类名称不能为空
   - 分类编码不能重复
   - 分类编码格式校验（大写字母+数字+下划线）
   ↓
5. 提交后端
   ↓
6. 后端处理：
   - 校验分类编码唯一性
   - 计算层级（父分类层级+1）
   - 插入数据库
   ↓
7. 返回成功，刷新树形结构
```

#### 2.4.2 删除分类流程

```
1. 用户点击"删除"按钮
   ↓
2. 弹出确认弹窗
   ↓
3. 后端检查：
   - 是否存在子分类
   - 是否有关联指标
   ↓
4. 如果存在关联数据：
   - 提示"该分类下存在子分类/指标，无法删除"
   ↓
5. 如果可以删除：
   - 执行软删除（status=0）
   - 或物理删除（根据业务需求）
   ↓
6. 返回成功，刷新树形结构
```

## 3. 指标库管理

### 3.1 功能概述

指标库管理是指标管理的核心模块，提供指标的统一查询、筛选、导入导出等功能。支持按指标名称、编码、分类、状态等多维度筛选，支持批量操作。

```

│ 首页 > 指标库管理                                    [关闭] │

│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 指标名称: [________] 指标编码: [________]               │ │
│ │ 指标分类: [请选择▼] 状态: [请选择▼]                     │ │
│ │ [查询] [重置]                                           │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                              │
│ 操作按钮                                                      │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ [+ 新增] [- 删除] [↑ 导入] [↓ 导出]                     │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                              │
│ 数据列表                                                      │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ ☑ | 序号 | 指标名称 | 指标编码 | 分类 | 单位 | 来源 | 状态 │ │

#### 3.2.2 筛选条件

- **指标名称**：文本输入框，支持模糊搜索
- **指标编码**：文本输入框，支持精确或模糊搜索
- **指标分类**：下拉选择框，从指标分类树中选择
- **状态**：下拉选择框，选项包括：
  - 全部
  - 启用（绿色标签）
  - 停用（红色标签）
  - 草稿（灰色标签）

#### 3.2.3 操作按钮

- **新增**：创建新指标，弹出新增指标弹窗
- **删除**：批量删除选中的指标（需二次确认）
- **导入**：批量导入指标数据（Excel模板）
- **导出**：导出当前筛选结果（Excel格式）

#### 3.2.4 表格列

| 列名 | 说明 | 示例 |
|------|------|------|
| 复选框 | 多选行数据 | ☐ |
| 序号 | 自动编号 | 1, 2, 3 |
| 指标名称 | 指标中文名称 | 地区生产总值(GDP) |
| 指标编码 | 指标唯一标识 | JJ001 |
| 指标分类 | 所属分类 | 经济指标 |
| 计量单位 | 指标单位 | 亿元、%、人 |
| 数据来源 | 数据出处 | 统计局、人社局 |
| 状态 | 启用/停用 | 启用（绿色）、停用（红色） |
| 创建时间 | 创建日期时间 | 2023-05-05 16:00:00 |
| 操作 | 操作按钮 | 修改、删除、详情 |

#### 3.2.5 操作列按钮

- **修改**：编辑指标信息
- **删除**：删除指标（需二次确认）
- **详情**：查看指标完整信息（只读）

#### 4.2.1 新增指标弹窗

```

│                                                              │
│ * 指标名称: [________________________]                       │

- **指标类型**：
  - 必须选择
  - 选项：原子指标、衍生指标、复合指标

- **数据类型**：
  - 必须选择
  - 选项：数值、文本、日期

- **所属主题域**：
  - 必须选择
  - 从指标分类树中选择

- **业务口径**：
  - 不能为空
  - 长度限制：10-2000字符
  - 清晰描述计算逻辑

  - 选填
  - 长度限制：0-500字符

- **状态**：
  - 必须选择

#### 6.2.2 左侧分类树

- **搜索框**：支持搜索分类名称
- **分类树**：
  - 根节点：全部
  - 一级分类：业务指标、系统指标
  - 二级分类：支持无限层级
  - 点击分类节点，右侧显示该分类下的指标

#### 6.2.3 右侧指标列表

- **表格列**：
  - 选择列：复选框，支持多选
  - 指标名称：指标中文名称
  - 指标类型：指标分类
  - 单位：指标单位
  - 更新时间：最后更新时间
  - 操作：添加按钮（快捷添加）

- **操作**：
  - 勾选多个指标，点击底部"确定"批量添加
  - 点击操作列的"添加"按钮，单个添加

#### 6.2.4 搜索功能

- **搜索框**：支持搜索指标名称
- **实时搜索**：输入关键词后，实时过滤指标列表
- **搜索范围**：当前选中分类或全部分类

### 6.3 业务流程

#### 6.3.1 打开指标选择器

```
1. 用户点击"添加指标"按钮
   ↓
2. 弹出指标选择器
   ↓
3. 加载分类树
   ↓
4. 加载指标列表（默认显示全部或第一个分类）
```

#### 6.3.2 搜索指标

```
1. 用户在搜索框输入关键词
   ↓
2. 前端实时过滤：
   - 过滤指标名称包含关键词的指标
   ↓
3. 更新指标列表
```

#### 6.3.3 选择分类

```
1. 用户点击左侧分类节点
   ↓
2. 前端处理：
   - 记录当前选中的分类ID
   ↓
3. 请求后端：
   - 查询该分类下的指标
   ↓
4. 更新指标列表
```

#### 6.3.4 批量选择指标

```
1. 用户勾选多个指标
   ↓
2. 点击"确定"按钮
   ↓
3. 前端处理：
   - 获取选中的指标ID列表
   - 调用父组件回调函数
   ↓
4. 关闭弹窗
   ↓
5. 父组件处理：
   - 将指标添加到表格
   - 显示指标信息
```

#### 6.3.5 单个添加指标

```
1. 用户点击操作列的"添加"按钮
   ↓
2. 前端处理：
   - 获取当前行的指标ID
   - 调用父组件回调函数
   ↓
3. 关闭弹窗
   ↓
4. 父组件处理：
   - 将指标添加到表格
   - 显示指标信息
```
