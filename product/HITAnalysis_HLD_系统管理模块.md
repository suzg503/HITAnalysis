## 1. 模块概述

### 1.1 模块定位

系统管理模块是HITAnalysis平台的**基础设施管理中心**，负责平台运行所需的系统配置、数据源管理、日志监控等功能，是保障平台稳定运行和数据安全的核心支撑模块。

### 1.2 模块价值

- **数据源管理**：统一管理外部数据连接，支持多数据源接入
- **系统配置**：集中管理平台运行参数，保障系统正常运行
- **安全审计**：完整的操作日志和登录日志，满足安全合规要求
- **运维监控**：实时监控系统运行状态，及时发现和处理异常
- **AI流程追踪**：完整记录AI创建指标的全流程，支持问题排查和优化

### 1.3 模块结构

```
系统管理
├── 🔌 数据连接管理
│   ├── 连接列表管理
│   ├── 连接配置维护
│   ├── 连接测试验证
│   └── 连接状态监控
├── 📊 数据表管理
│   ├── 数据表列表
│   ├── 元数据同步
│   ├── 表结构查看
│   └── 同步状态管理
├── 📧 邮件设置
│   ├── SMTP服务器配置
│   ├── 发件人信息设置
│   ├── 邮件测试发送
│   └── 邮件模板管理
├── 📝 系统日志
│   ├── 登录日志
│   ├── 操作日志
│   ├── AI流程日志
│   └── 系统异常日志
└── 📖 接口文档
    ├── 接口列表展示
    ├── 接口详情查看
    └── 接口测试工具
```

## 2. 功能模块概要设计

### 2.1 数据连接管理

#### 功能定位
管理平台对外部数据源的连接配置，支持多种数据库类型的接入。

#### 核心功能
1. **连接列表管理**
   - 分页列表展示所有数据连接
   - 支持按连接名称、类型、状态筛选
   - 支持批量操作（启用、停用、删除）

2. **连接配置维护**
   - 连接名称（必填）
   - 数据库类型（下拉选择：MySQL、PostgreSQL、Oracle、SQL Server等）
   - 主机地址、端口、数据库名
   - 认证信息（用户名、密码）
   - 连接参数配置（超时时间、连接池大小等）

3. **连接测试验证**
   - 一键测试连接可用性
   - 显示连接测试结果（成功/失败、响应时间）
   - 错误信息详细提示

4. **连接状态监控**
   - 连接状态显示（正常、异常、未测试）
   - 最后测试时间
   - 连接使用统计

#### 数据模型（概要）
```
数据连接表（sys_data_source）
├── id：连接ID
├── connection_name：连接名称
├── database_type：数据库类型
├── host：主机地址
├── port：端口
├── database_name：数据库名
├── username：用户名
├── password：密码（加密存储）
├── connection_params：连接参数（JSON）
├── status：状态（启用/停用）
├── test_status：测试状态
├── last_test_time：最后测试时间
├── created_by：创建人
└── created_at：创建时间
```

### 2.2 数据表管理

#### 功能定位
管理已连接数据源中的数据表元数据，支持表结构同步和查看。

#### 核心功能
1. **数据表列表**
   - 按数据源分组展示数据表
   - 支持按表名、所属库筛选
   - 显示表的基本信息（表名、别名、行数、大小）

2. **元数据同步**
   - 手动触发元数据同步
   - 自动定时同步（可配置）
   - 同步状态显示（同步中、已完成、失败）
   - 同步时间记录

3. **表结构查看**
   - 查看表的字段列表
   - 字段属性展示（名称、类型、长度、是否必填、注释）
   - 索引信息展示

4. **同步状态管理**
   - 同步进度显示
   - 同步日志查看
   - 异常处理指引

#### 数据模型（概要）
```
数据表元数据表（sys_table_metadata）
├── id：记录ID
├── data_source_id：数据源ID
├── database_name：数据库名
├── table_name：表名
├── table_alias：表别名
├── table_comment：表注释
├── row_count：行数
├── table_size：表大小
├── sync_status：同步状态
├── last_sync_time：最后同步时间
├── created_at：创建时间
└── updated_at：更新时间
```

### 2.4 系统日志

#### 功能定位
记录系统运行过程中的各类日志，支持安全审计、问题排查和流程监控。

#### 核心功能

##### 2.4.1 登录日志
- **日志记录**：用户登录/登出的完整记录
- **记录内容**：
  - 用户名、登录IP、浏览器信息、操作系统
  - 登录时间、登录状态（成功/失败）
  - 失败原因（密码错误、账号锁定等）
- **查询功能**：按用户名、时间范围、状态筛选
- **导出功能**：支持日志导出（Excel）

##### 2.4.2 操作日志
- **日志记录**：用户在系统中的关键操作记录
- **记录内容**：
  - 操作用户、操作模块、操作内容
  - 操作IP、操作时间、操作状态
  - 请求参数、响应结果
- **模块覆盖**：指标管理、报表管理、看板管理、系统设置等
- **查询功能**：按用户、模块、时间、状态筛选

##### 2.4.3 AI操作日志（新增核心模块）

**日志定位**：完整记录AI创建指标、AI问答、AI生成报告、AI预警、AI推荐的全流程，支持问题排查、合规审计、AI优化分析。

**日志类型矩阵**：

| 日志类型 | 记录内容 | 关键字段 | 用途 |
|----------|----------|----------|------|
| AI问答日志 | 用户问题、AI生成的SQL、查询结果、解读内容 | 用户输入原文、AI响应、置信度评分 | 审计AI回答准确性 |
| AI报告日志 | 报告类型、生成参数、报告内容、生成耗时 | 报告模板、生成参数、报告内容 | 报告生成追溯 |
| AI预警日志 | 预警触发条件、预警内容、推送记录 | 预警规则、预警数据、推送方式 | 预警效果评估 |
| AI指标创建日志 | 流程各阶段详情（需求理解→设计→生成→验证→发布） | flow_id、各步骤输入输出、耗时 | AI指标创建全链路追踪 |
| AI推荐日志 | 推荐场景、推荐结果、用户反馈 | 推荐算法、推荐指标列表、用户评分 | 推荐算法优化 |

**详细记录内容**：

1. **AI问答日志**
   - 用户输入的自然语言问题原文
   - AI识别的意图和提取的关键信息
   - AI生成的SQL查询代码
   - 查询结果数据（前100条样本）
   - AI生成的数据解读文字
   - 置信度评分（AI对回答质量的自我评估）
   - 操作时间、操作用户、操作IP、所属科室

2. **AI报告日志**
   - 报告类型（日/周/月运营简报、质量简报、效率简报）
   - 报告生成参数（时间范围、科室范围、报告模板）
   - 生成的报告内容（文字总结 + 图表 + 异常说明 + 建议）
   - 报告导出格式（PDF/Word）
   - 生成耗时、成功率

3. **AI预警日志**
   - 预警触发条件（指标阈值、异常波动检测）
   - 预警内容（预警指标、当前值、阈值、异常原因）
   - 推送方式（站内消息、短信、企业微信、邮件）
   - 推送时间、推送状态、接收人员
   - 预警处理状态（已处理/未处理）

4. **AI指标创建日志**（详细流程）
   - 流程ID（flow_id，唯一标识一次AI创建流程）
   - 用户ID、会话ID、操作IP、所属科室、角色
   - 流程步骤（需求理解 → 指标设计 → 代码生成 → 验证测试 → 发布上线）
   - 每步骤的输入数据、输出数据、耗时、状态
   - AI模型信息（Qwen2.5-7B）、Prompt内容、AI响应
   - 异常信息、错误堆栈
   - 流程总耗时、最终状态（成功/失败）

5. **AI推荐日志**
   - 推荐场景（首页看板、指标推荐、报表推荐）
   - 用户角色、岗位信息
   - 推荐算法类型（协同过滤、内容推荐、混合推荐）
   - 推荐指标列表/推荐看板列表
   - 用户反馈（采纳/忽略、评分）

**日志查询功能**：
- **多维筛选**：按用户、时间范围、操作类型、关键词、状态、科室筛选
- **关键词检索**：搜索日志内容中的关键词
- **流程回放**：支持查看完整AI流程的步骤回放（按flow_id查看所有步骤）
- **导出功能**：支持导出Excel格式（含完整日志详情）

**日志审计特性**：
- **不可删除**：日志记录不可删除，保留完整审计链
- **不可篡改**：日志记录不可修改，保证数据真实性
- **数据加密**：敏感信息加密存储
- **定期归档**：历史日志定期归档（超过90天）

**日志统计分析**：
- AI成功率统计（各类型AI操作成功率）
- 平均耗时分析（各类型AI操作平均耗时）
- 常见错误分析（失败原因统计、高频错误类型）
- 用户使用热力图（哪些用户高频使用AI功能）
- AI优化建议（基于日志数据生成AI模型优化建议）

**日志页面路径**：
系统设置 → 系统操作日志 → AI操作日志

**日志数据保留策略**：
- 活跃日志：保留90天（可实时查询）
- 归档日志：保留365天（归档存储，查询需解冻）
- 历史日志：超过365年可按合规要求处理（删除或永久归档）

##### 2.4.4 系统异常日志
- **日志记录**：系统运行异常、错误信息
- **记录内容**：
  - 异常类型、异常信息、堆栈跟踪
  - 发生时间、发生模块、影响范围
  - 处理状态、处理人、处理结果
- **告警功能**：严重异常实时告警（邮件、短信）

#### 数据模型（概要）

├── ip_address：登录IP
├── browser：浏览器
├── os：操作系统
├── login_time：登录时间
├── login_status：登录状态
├── fail_reason：失败原因
└── created_at：创建时间

操作日志表（sys_operation_log）
├── id：日志ID
├── user_id：用户ID
├── username：用户名
├── module：操作模块
├── operation：操作内容
├── method：请求方法
├── url：请求URL
├── params：请求参数
├── ip_address：操作IP
├── operation_time：操作时间
├── status：操作状态
├── error_msg：错误信息
└── duration：耗时（毫秒）

AI流程日志表（sys_ai_flow_log）
├── id：日志ID
├── flow_id：流程ID（唯一标识）
├── user_id：用户ID

## 3. 核心流程设计

### 3.1 数据连接配置流程

```
用户点击"新增连接"
  → 填写连接信息（名称、类型、主机、端口、数据库、用户名、密码）
  → 配置连接参数（超时时间、连接池大小等）
  → 点击"测试连接"
  → 系统尝试建立连接
  → 显示测试结果（成功/失败、响应时间）
  → 测试成功后点击"保存"
  → 加密存储连接信息
  → 返回成功提示
  → 刷新连接列表
```

### 3.2 元数据同步流程

```
用户选择数据源
  → 点击"同步元数据"
  → 系统连接数据源
  → 获取表列表和表结构
  → 对比本地元数据
  → 更新/新增/删除元数据记录
  → 更新同步状态和时间
  → 返回同步结果（新增表数、更新表数、删除表数）
```

### 3.3 AI指标创建流程监控

```
用户发起AI创建指标请求
  → 记录流程开始日志（flow_id、user_id、session_id）
  → 步骤1：需求理解
    → 记录用户输入的自然语言需求
    → 记录AI理解的意图和提取的关键信息
    → 记录步骤耗时和状态
  → 步骤2：指标设计
    → 记录AI生成的指标定义
    → 记录业务口径和计算逻辑
    → 记录步骤耗时和状态
  → 步骤3：代码生成
    → 记录生成的SQL/ETL代码
    → 记录代码审查结果
    → 记录步骤耗时和状态
  → 步骤4：验证测试
    → 记录测试数据和验证结果
    → 记录数据质量检查结果
    → 记录步骤耗时和状态
  → 步骤5：发布上线
    → 记录发布状态和上线时间
    → 记录生效范围
    → 记录步骤耗时和状态
  → 记录流程结束日志（总耗时、最终状态）
  → 异常处理：记录异常信息、触发告警
```

## 4. 数据权限设计

### 4.1 权限模型

```
用户（User）
  └── 角色（Role）
       └── 权限（Permission）
            ├── 数据连接：查看/新增/编辑/删除/测试
            ├── 数据表：查看/同步
            ├── 邮件设置：查看/配置/测试
            ├── 系统日志：查看/导出
            ├── AI流程日志：查看/导出/回放
            └── 接口文档：查看/测试
```

### 4.2 数据范围权限

- **全部数据**：系统管理员
- **本部门数据**：部门管理员
- **个人数据**：普通用户（仅查看自己的操作日志）

## 5. 性能优化设计

### 5.1 查询优化

- **索引优化**：日志表按时间、用户、模块建立索引
- **分页查询**：所有列表查询必须分页
- **数据归档**：历史日志定期归档（超过90天）
- **缓存策略**：数据连接配置缓存（Redis）

### 5.2 日志写入优化

- **异步写入**：日志采用异步方式写入，避免影响主业务
- **批量写入**：高频日志采用批量写入方式
- **日志分级**：按级别过滤，减少不必要的日志写入

## 7. 前端交互设计

### 7.1 页面状态管理

- **列表页**：筛选条件、表格数据、分页信息
- **配置页**：表单数据、校验信息、提交状态
- **日志详情页**：只读数据展示、流程回放

### 7.2 用户交互提示

- **操作成功**：Toast提示"操作成功"
- **操作失败**：Toast提示错误信息
- **删除确认**：二次确认弹窗
- **测试连接**：进度提示、结果展示

### 7.3 响应式设计

- **桌面端**：左侧菜单 + 右侧内容区
- **平板端**：折叠菜单，简化布局
- **移动端**：暂不支持（后台管理系统）
